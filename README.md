<p align="center">
    <b>DFreds Pocket Change</b> is a FoundryVTT module which automatically adds currency to actors when their tokens are dropped on the canvas, using a treasure table you configure.
</p>

## Features

- Automatically generates currency when a token is dropped on the canvas
- Roll new currency at any time from a button on the actor sheet
- Configure everything through one menu:
  - The actor value that decides how much treasure is generated, such as the challenge rating
  - The roll made to pick a result, and the roll made for each currency amount
  - The currencies that get filled in and where they are stored on the actor
- Choose which actors receive currency with required checks and any-of checks,
  so you can require an NPC while accepting several creature types
- Set a percent chance that no currency is generated at all
- Works with any game system, with autocomplete for actor values
- Comes set up with the DMG Individual Treasure tables by Challenge Rating on dnd5e
- Optionally reports the rolls and the resulting currency in a chat message to GMs
